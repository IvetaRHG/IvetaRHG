## 🛠 Проекты

Пока у меня семь проектов: три учебных уже опубликованы на GitHub, ещё четыре —
первые работы, сделанные во время обучения и по работе.
Все они совсем простые. Но именно с них начинается путь, и я двигаюсь дальше.

**1. 🏠 [Ипотечный калькулятор с дашбордом](https://github.com/IvetaRHG/ipoteka-dashboard)**
Интерактивный дашборд на Streamlit: 6 KPI-метрик, 5 графиков (heatmap и схема Санки), график платежей с выгрузкой в CSV и сравнение схем платежа.
`Python` · `Streamlit` · `Plotly` · `pandas`

**2. 🧭 [Маршрут — планировщик поездки](https://github.com/IvetaRHG/marshrut-trip-planner)**
Адаптивное приложение путешественника: маршрут по дням, бюджет, бронирования и чек-лист — без фреймворков, сборки и зависимостей.
`HTML` · `CSS` · `JavaScript` · `localStorage`

**3. 🤖 [Алина — чат-бот для сообщества ВКонтакте](https://github.com/IvetaRHG/alina-vk-ai-consultant)**
AI-консультант по учебным курсам: диалог с контекстом, ответы строго по базе знаний, передача заявки в отдел продаж.
`Python` · `GigaChat API` · `VK Long Poll`

**4. Личный блог**
Адаптивный блог с переключением светлой и тёмной темы и фильтром записей по тегам.
`HTML` · `CSS` · `JavaScript`

**5. Интернет-магазин**
Каталог товаров, корзина и оформление заказа — вся логика на чистом JavaScript.
`JavaScript` · `API` · `Адаптив`

**6. Лендинг для студии**
Продающая одностраничная страница с плавными анимациями появления блоков при прокрутке.
`HTML` · `CSS` · `Анимации`

**7. Проект по работе**
Небольшая автоматизация рабочей задачи.
`Автоматизация`
